# Memory Palace

This file serves as a centralized context repository (Memory Palace) for the INKAPORTAL project. It is designed to be highly compressible to save tokens.

## Architecture
- Next.js 16.2.4 App Router
- Prisma + SQLite
- Tailwind CSS v4, Framer Motion
- Mapbox GL JS

## Goals
- Maintain a highly compressed technical context for AI agents.
- Ensure the project adheres to a Feature-Sliced Architecture.
- Provide a single source of truth for architectural constraints and project roadmap.
